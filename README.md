## The entry

> I've escalated your case to Tier 3. That's just me again, but this time I'll read your ticket back in a deeper voice.

117 characters. One funny line from a hopeless tech support agent to a
desperate customer — the cheerful uselessness of an "escalation" that
goes nowhere, with the punchline at the end.

## How it works

`main.py` (Python standard library only, no network) writes the line to
`/output/entry.txt`, asserting the 1–199 character gate first.

```sh
python3 -P -s main.py
cat /output/entry.txt
```
